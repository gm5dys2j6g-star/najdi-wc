NAJDI WC – GitHub Pages

1. Nahraj soubor index.html do repozitáře GitHubu.
2. V Settings → Pages nastav Deploy from a branch.
3. Branch: main, folder: / (root).
4. Ulož.
5. Po nasazení bude web dostupný přes adresu GitHub Pages.

Poznámka: GPS v Safari funguje pouze přes zabezpečené HTTPS připojení.
Ukázková data WC jsou zatím z Krnova; později lze napojit skutečná data.
